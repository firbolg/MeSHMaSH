## MeSHMaSH

A script for comparing existing MeSH indexing for emerging social determinants of health (SDOH) concepts.

-Checks titles of all articles in PubMed for a list of SDOH terms which are NOT in MeSH
n/-Checks this set of articles for MeSH terms
-Counts and sorts the MeSH terms previously used to index the SDOH term
-Collates each SDOH term with the top associated MeSH terms
-Saves everything as a .csv file
